# 油价查询助手 - 设计文档

## 项目概述

**项目名称：** 油价查询助手
**创建日期：** 2026-03-09
**目标用户：** 个人日常查询使用
**核心功能：** 查询当前油价、查看历史趋势、预测下次调价

## 使用场景

个人用户通过手机浏览器快速查看当前油价和历史趋势，帮助决定加油时机。支持一线城市（北京、上海、广州、深圳）切换。

## 技术方案

### 整体架构

**方案选择：** 纯静态页面 + 第三方 API

**技术栈：**
- HTML5 + CSS3（响应式设计）
- 原生 JavaScript（无框架依赖）
- Chart.js（图表库，CDN 引入）
- 第三方油价 API（聚合数据或天行数据）

**部署方式：** GitHub Pages / Vercel / Netlify

## 核心功能实现

### 1. 初始化流程

```
页面加载
  ↓
检查 localStorage 中的默认城市
  ↓
如无设置，使用深圳作为默认城市
  ↓
检查缓存数据是否有效（1小时内）
  ↓
有效：使用缓存 | 无效：调用 API
  ↓
渲染页面（油价卡片 + 调价预告 + 历史图表）
```

### 2. 城市切换功能

- 用户从下拉框选择城市
- 保存选择到 localStorage
- 重新获取该城市数据
- 平滑过渡更新页面内容

### 3. 数据获取与缓存

**API 调用封装（api.js）：**
```javascript
async function getOilPrice(cityId) {
  const cacheKey = `oilPrice_${cityId}_${getTodayDate()}`;
  const cached = getCache(cacheKey);

  if (cached) return cached;

  const data = await fetchFromAPI(cityId);
  setCache(cacheKey, data, 3600000); // 1小时
  return data;
}
```

### 4. 图表渲染

- 使用 Chart.js 绘制折线图
- X 轴：日期（近3个月）
- Y 轴：价格（元/升）
- 显示两条曲线：92# 和 95#
- 响应式适配移动端

### 5. 错误处理

**API 调用失败：**
- 显示友好提示："数据加载失败，正在使用缓存数据"
- 尝试使用缓存数据（即使过期）
- 提供"重试"按钮

**网络离线：**
- 检测 `navigator.onLine`
- 提示用户检查网络连接
- 自动使用缓存数据

**数据异常：**
- 验证 API 返回数据格式
- 缺失字段使用默认值或占位符

## 性能优化

### 加载优化
- Chart.js 使用 CDN 引入，利用浏览器缓存
- CSS 内联关键样式，减少首屏渲染时间
- 图标使用 SVG，无需额外请求

### 代码优化
- JavaScript 代码精简，避免冗余
- 使用事件委托减少事件监听器
- 防抖处理城市切换操作

### 缓存策略
- localStorage 缓存 API 响应
- 缓存有效期 1 小时
- 离线时优先使用缓存

## API 集成方案

### 推荐 API 服务

**方案 A：聚合数据（推荐）**
- 接口：https://www.juhe.cn/docs/api/id/76
- 免费额度：100次/天
- 数据准确，更新及时

**方案 B：天行数据**
- 接口：https://www.tianapi.com/apiview/94
- 免费额度：100次/天
- 备选方案

### API Key 处理

**初期方案（简单）：**
- API Key 直接写在前端代码中
- 适用于个人使用，访问量小
- 风险：Key 可能被滥用

**升级方案（推荐）：**
- 使用 Vercel Serverless Functions 代理 API 请求
- API Key 存储在环境变量中
- 前端调用自己的 serverless 接口

## 部署方案

### GitHub Pages 部署

1. 创建 GitHub 仓库
2. 推送代码到 `main` 分支
3. 在仓库设置中启用 GitHub Pages
4. 访问 `https://username.github.io/oil-price-tracker`

### Vercel 部署（推荐）

1. 连接 GitHub 仓库到 Vercel
2. 自动部署，支持 HTTPS
3. 可配置环境变量保护 API Key
4. 访问 `https://oil-price-tracker.vercel.app`
